# UI-03 — current mission card

Implemented locally 2026-09-10. UI-04 build redesign and UI-05 whole-interface acceptance remain queued. Nothing published. Existing uncommitted work preserved: the baseline diff and integration files were captured in `/tmp/ui03-baseline`; comparison before documentation edits confirmed only the four intended existing UI files changed. The new stylesheet and verification script are additional files. No model, save, camera, build-palette or simulation changes.

The bottom mission region now contains one current objective card. Desktop no longer duplicates it with the full mission rail or repeated detail headings. Both layouts show the title, task description, accessible progress and current/target count. Cash missions name their reward; land missions name their permit reward, and learned patterns retain their existing meaning. Tutorial progress counts completed lessons without inventing a cash reward.

Details expands secondary guidance inside the card while its heading, progress and actions stay visible. The full Jobs & city link action is always available. Actual build buttons retain tutorial highlights; duplicate tutorial tool shortcuts and focus controls remain in Details. Required acknowledgements, expansion and finish actions remain on the card. Explicit Skip retains its existing confirmation and outside-traffic behavior; opening or closing guidance does not skip a lesson. Manager briefings and safe-crossing actions retain their existing handlers.

The highlighted tool locator is compact; it yields its space while Details is open. Narrow docks may reserve up to half the frame height to keep the task actions usable. Longer descriptions and detail content scroll, with keyboard-focusable scroll regions. The existing measured viewport responds automatically.
