## Fixes

- Narrow statistics use two columns of inline label/value pairs. All six fields, live data, truthful Weather text and 17.6px type remain. Installed Claude implemented only `cityStats.css`; Codex reviewed and verified it.
- Tutorial guidance now shares the reserved feedback band immediately above the mission. Actual category/tool highlights and the dismiss action remain. Removing the duplicated guidance allocation gives the map more space.
- Mission titles stay anchored while long instructions/waiver text scroll beneath them. Progress, rewards and actions remain visible. Dock sizing accommodates rotation and two-line buttons, and Details cannot cover the current task's controls.

The selected narrow tutorial map increased from UI-04's approximately 102px high to 169–175px. Initial unselected narrow play provides approximately 223px. The build area remains below the mission on narrow and bottom-right on desktop; persistent controls stay outside the playable rectangle. Category switching, live prices, selection/locks, rotation, removal, expansion, camera focus/input, display preferences, saved towns and simulation rules are retained.

## Remaining limits

The compact map is substantially larger but still benefits from pan/zoom on phones. Long task copy, secondary guidance, alerts and Dashboard content scroll inside reserved regions. This is Chromium with emulated touch, not physical-device comfort/performance testing, a screen-reader session, hardware safe-area testing or RUN host lifecycle acceptance. The full tutorial uses accelerated model time for waiting, so it does not establish real-time pacing or player enjoyment. Those limits are not unfinished UI-01–05 implementation items, and no public release or user playtest approval is claimed.
