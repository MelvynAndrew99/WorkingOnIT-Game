# UI-02 — unified statistics and actions

Implemented locally 2026-09-10. UI-03/04 mission and build redesigns remain queued. No publication. Existing uncommitted work retained; the scene changes since UI-01 only expose saved elapsed time and rename the report message to Dashboard. No simulation rules or save schema changed.

Installed Claude delivered only `CityStats.tsx` and `cityStats.css` under a bounded assignment. Codex reviewed and integrated those files, the HUD snapshot, global actions, reserved Dashboard, and verification. The baseline tracked patch and integration-file copies were captured under `/tmp/ui02-baseline` before editing.

Six semantic label/value pairs now share one top bar: Funds, Visitors, On Road, Fatalities, Time, Weather. Exact funds remain accessible when abbreviated. Visitors uses parked shopping/leisure visits; On Road excludes visiting/crashed journeys and emergency crews. Definitions appear in Dashboard and stat titles. The saved elapsed clock uses unbounded hours and freezes with simulation pause. Counters have no live announcement region.

Heatmap toggles the existing stopped-traffic diagnostic and exposes pressed state plus a reserved legend. Dashboard retains report content, Access/Visitors modes, rescue information and Debug. Dashboard and Debug occupy the same reserved side panel, one at a time. Dashboard focuses its heading; Close/Escape restores its trigger. Pause retains the existing modal and construction blocking. Menu retains save/continue behavior.
