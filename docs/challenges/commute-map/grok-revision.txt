# Commute Map — production layout

One continuous **top-down modern town** for sites **1–25**, same golden-hour world as the title: grey asphalt, double yellows, white crosswalks, cream/grey flat roofs, leafy sidewalks, ordinary shops, downtown silhouettes on the horizon. **No district bands, no palette swaps, no second theme.** Landmarks are scenery on one commute, not UI chapters.

**Play rules (unchanged):** IDs `1–4` always selectable; real save receipts only. **5–25 never launch** (5 is the authored frontier). Suggested stop = first unfinished among 1–4; if all four are done, The Man stands at **5**. Sandbox stays in the header. Briefings keep real objectives. Numbers remain in `aria-label` + briefing (and a tiny tag).

## Viewport
**390×844:** compact sticky bar (~48px). Map is a **pannable 2D city** (touch-drag + scroll); do **not** use a vertical node list. Default camera frames the suggested pad with ~80px of street around it.  
**1440×900:** same art, wider crop (more blocks visible), still **centered on the suggested pad**.  
Pads **52px**, hit **44px+**, ~100–130px path spacing so a **face reads**. `prefers-reduced-motion`: no path walk, camera jump.

**Header (not a banner):** Main Menu · wordmark **Working ON IT!** · **Sandbox** · ribbon tally (count of completed 1–4 only). No stars, lives, or fake locks.

## City geography (one route)
Paint **one town**, path following real streets:

- **SW start:** corner **COFFEE**, residential side streets, morning queue. Pads **1–4** here (only live jobs).
- **Works yard:** cones, direction board, modest plaque on a tiny curb cut. Pad **5** = survey/construction, not playable.
- **School run + park:** crosswalk, playground, arterial. **6–12** along the loop (upcoming).
- **Canal bridge + supermarket:** same town, small parking apron. **13–18**.
- **Clinic approach / downtown edge:** hospital bay, civic roof in the distance (aspiration, not a new biome). **19–25**.

Landmarks stay in the mural; **live pads and the connecting route sit in a quiet ~64px road corridor** with no baked numerals, buttons, or character.
