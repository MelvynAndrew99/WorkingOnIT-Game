# Main menu redesign — delivered locally

The title now fills the available device viewport. Desktop uses a large typographic title and road-sign controls beside the existing manager/traffic illustration. Phones use a stacked title, compact illustration and actions. The original image is unchanged; CSS frames its illustration separately from its painted title and menu.

Start your city / Continue commute is the strongest action; Challenges remains a gold sign with less visual weight. Settings and New city use matching gold road-sign styling in a compact utility row. The title-screen tagline is “Fix the commute.”; the credit-taking theme is reserved for gameplay, per user feedback. New city appears only with an existing town and retains the existing destructive-reset confirmation. Skip tutorial remains available in Settings and in the existing tutorial UI. The title always follows the actual viewport; gameplay retains its saved display preference.

Actual installed Claude and Grok provided text-only design reviews (adjacent files). Codex selected the layout, implemented it and verified it. Both reviews recommended distinguishing the primary action from Challenges; adopted through size, color and indentation. Suggestions to hide Challenges from new players, invent city statistics, or turn Skip into a replay toggle were not adopted. The scene caption now reads “Good as new!” beside the obvious road patch. Its CITY MANAGER label has faded, worn CI and AGER, leaving TY MAN prominent—a possible “Thank You Man” reading requested by the user. The whole caption card uses aged paper, chipped edges, stains and creases, including around the crisp “Good as new!” quote. CI has milder irregular fading so CITY remains recognizable; AGER retains its stronger fading and authored SVG scuff mask. The mobile scene is taller and its caption sits above the patch so the visual joke remains visible.

Verification: production TypeScript/Vite build passes. Isolated Chromium at 1440×900 and 390×844 verifies full viewport width, visible 44px-or-larger action targets, Settings and saved portrait preference without narrowing the title, challenge entry, returning-town detection, cancel-reset data preservation and actual Continue entry to the game canvas. No page errors. Fresh/returning screenshots inspected in `evidence/`. No player save or simulation rules changed; no publication. Physical-device feel remains for playtesting.

Reproduce: local Vite on port 5197, `mkdir -p /tmp/title-menu-review`, then run `verify.mjs` with `PLAYWRIGHT_MODULE` and `CHROMIUM_PATH` pointing at existing installations. The script uses isolated browser contexts and blocks external requests.

Latest refinement: retain the worn paper card (sticky-note idea canceled). “Good as new!” uses the locally bundled OFL-licensed Kalam handwriting font, with the faded CITY MANAGER letterhead unchanged. A framed version on his wall remains a future-game idea; no frame or sticky-note redesign implemented. Font source: Google Fonts `ofl/kalam`, license included in `public/fonts/kalam/OFL.txt`.
