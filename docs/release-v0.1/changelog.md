# Working ON IT! v0.1

Build a town, watch its commutes and improve the roads that keep people moving.

- Guided onboarding now points to the actual construction tools, with mobile callouts and highlights. Build your own town; the old Practice district placement is retired.
- Homes, stores and parks generate real visits and income. Smaller starting funds and finite tutorial construction waivers keep earning and experimenting meaningful.
- Shape routes, place stops and lights, and divert traffic around accidents. Emergency crews can cross diversions and pass queues when there is safe space; rescue deadlines still matter.
- Continue the same town through map expansion and an optional outside-city connection. Phone and desktop layouts, pan/zoom and saved display preferences support growing layouts.

This is the first v0.1 gameplay milestone label. RUN's technical upload version continues the existing game's version sequence.
