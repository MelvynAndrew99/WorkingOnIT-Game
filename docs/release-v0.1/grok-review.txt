## Proposed reusable lessons (not edits)

1. **Name the dock the same as the lesson.** “Clinic” in copy and “Hospital” on the tool is a findability bug, not flavor.
2. **A model test that calls `acknowledge-safety` does not prove the player can.** If completion is a UI action, the ship check is that control on the taught path.
3. **Rejecting a save to protect grants is correct accounting and dangerous on a live namespace.** `parseCity` null + `loadSave` fallback = new town. Public updates need a real old save, not only malformed-fixture tests.
4. **Do not advertise dispatch teaching from the ack path.** That path records an explanation and zero rescues. Say so in player copy if the rescue body still says “Watch police clear a crash.”

I am not recommending a delay for unfinished comedy, crisis charges, or audio. I am recommending the ack/Understood visibility check and one real public-save parse before the rundot upload.
