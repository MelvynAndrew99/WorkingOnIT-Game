## The diagnosis

The problem wasn't type size — it was that **four full-width bands each answered "what do I do next?"**: header, tutorial coach, mission strip, dock. That left 229px of map at 320×640, and on a 1440px desktop it just made the same bands wider.

## The layout

**One objective panel** replaces the coach + mission strip, with a strict priority: crash → claimable reward → lesson → current job. When a job completes, the panel *becomes* `Claim $200`. Explanation lives behind **More** on a phone, always open in the desktop rail.

**Two reserved bands only** (header, dock) — the renderer keeps measuring exactly the elements it already measures, so it needs no change to work. Camera controls became an edge rail and the Map modal is gone entirely.

**Desktop composes horizontally**: 312px left rail (objective + all four jobs), 152px right rail (labelled camera controls + live traffic readout), and a dock showing **all eleven tools at once** with no category tabs. Composition keys off a measured `#app-frame` width, not the viewport, since a desktop player can force the portrait frame.
